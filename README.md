Frame is being built to produce complete AI-directed films. The slideshow was rejected as product acceptance. Backend 0.8.5 now has separate writer, director, editor and reviewer calls, timestamped shot actions and exact-image approval before animation for new drafts. 189 mocked tests and an isolated browser walkthrough verify those safeguards; they do not establish live creative quality. Actual media review, richer editing and the mobile connection remain unfinished. Owner TestFlight 2.0.0 (1), listed as “Frame: Photos to Reels,” remains a separate offline editor with 44 native tests, no Frame login and no cloud AI integration. Real-device acceptance is still pending.

My product work focuses on specific workflows: customer support, equipment quotations, leasing and video production. Each product has a defined development stage and next validation milestone. Dubai Game is exploratory work in preproduction.

Each project page includes its intended users and buyers, product screenshots, technical and commercial readiness, and the evidence still needed before the next stage.
